Lead A · Average error and individual-token agreement

Claim and registered rule. Entry 0029 states: “Not one included handoff has a single matched token whose centered deviation exceeds τK.” Entry 0023 defines f* as the smallest fraction of largest-error tokens whose removal leaves the remaining mean at or below τK ≈ 0.3186. The registered band result is HOLDS when median f* is at most 0.15. The statistic and claim are linked to the pinned lines.

Attack attempted. Recompute the archived f* arithmetic from token errors, check stricter thresholds, and count tokens individually above tolerance. A passing mean and individual-token claim can then be compared directly.

Raw artifacts read. Archived score and token files for 85 handoff/configuration observations spanning 60 distinct handoffs. The original review checked 170 file hashes and reproduced 1,204 numerical comparisons. The replicator checks all available archived file hashes before computing.

Evidence. Each observation had f* = 0 at the registered threshold, while individual key-token errors exceeded it at these rates:

Django 10999 trace 54 is a native-short example: 1,118 of 3,953 token errors exceed the threshold, but its mean is 0.220743, below 0.318644. Its f* is zero. The native-short median f* is 0 at thresholds 0.3186 and 0.10, and 0.1433 at 0.03.

Finding. SURVIVES for the registered arithmetic and original band result. REFUTED for the claim that every matched token is within tolerance. This matches the correction recorded in entry 0038.

Interpretation and limits. A mean can pass while individual values exceed the threshold. f* is an oracle lower bound: it assumes exact repairs and ignores errors propagated through other reused states. The stricter-threshold results describe sensitivity; alternative calibration splits were not refitted.

Lead B · Exactly-zero prefix control

Claim and registered rule. Entry 0025 compares a prompt with the same prompt plus one later token. Its original prefix must have maximum normalized error at or below 0.0001. See the registered control.

Attack attempted. Check whether the control compared one cache with itself and whether an intentionally altered cache was used to measure error detection.

Raw artifacts read and evidence. The pinned implementation separately prefills the original prompt and the extended prompt. Earlier positions cannot attend to a later appended token, so equal prefix states are expected from this control. A same-object score is a separate identity check.

Finding. SURVIVES for a separate-forward-pass implementation. UNEVALUABLE for whether the control rejects a deliberately planted error; that sensitivity test was not run.

Interpretation and limits. The zero result is consistent with the registered causal prefix control. Later shuffled-cache answer tests measure another behavior and do not test this historical error gate.
