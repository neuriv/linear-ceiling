Pinned inputs · one-command rerun scripts

Replication instructions

These commands reproduce the experiment families described in the results. Run them from the repository root. Model and archive files download into ignored local folders; they are not committed here.

Environment and storage

The recorded full run used an Apple M5 with MPS. Use Python 3.11 or newer and the versions in requirements.txt. MPS timings depend on the Mac; CPU runs reproduce the comparisons but not those timing values.

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt

The pinned model and archive downloads total about 16.5 GB. Reserve around 30 GB of disk space for downloads, model caches, prompt caches, and intermediate results. No model-host token is required for these public revisions.

1. Download the fixed sources

python fetch_records.py
python download_models.py 2>&1 | tee models.log

Each download is pinned in fetch_records.py or download_models.py; fetched file hashes are saved in the generated source manifests.

2. Prepare fixed examples

python prepare_inputs.py
python prepare_math.py
python prepare_handoffs.py
python probe.py

The first three commands save the selected excerpt IDs, GSM8K prompts, extraction questions, and source paths. The probe records hardware timing and a cache round-trip control. The scored runs below retain their preselected dtypes regardless of probe results.

3. Recompute the archived-record review

python audit_records.py

This downloads no additional data after step 1. It checks each score and token file against its archived SHA-256, recomputes the average-based key statistic, and counts individual key tokens above the registered threshold. It writes archive-audit.json.

4. Run short injection and checkpoint comparisons

python local_experiments.py
ZERO_LAG_CONTROL=1 python continuations.py
python continuations.py
LOCAL_STUDY=highcoverage python local_experiments.py

The first command runs sparse injection and the checkpoint comparison; the second checks eight same-checkpoint continuations; the third runs the 24 cross-checkpoint continuations; the final command runs the eight higher-coverage injection cases. Case-level outputs go to ignored local-results*/ folders.

5. Score answers, scaling, and complete-history reuse

python math_run.py writer --device mps --dtype float16
python math_run.py reader --device mps --dtype float16
python math_recheck.py
python factorial.py --device mps --dtype float16 --chunk 256
python practical.py --device mps --dtype float16
python history_ablation.py
python summarize.py

These steps reproduce the GSM8K scoring and precision recheck, the context-scaling comparison, complete-history block reuse, history erasure, and the final local JSON summary. Preserve the generated JSON files if you want the fresh case-level records; the .gitignore keeps downloaded weights and caches out of Git.

Recorded outcomes versus new runs. results/historical-summary.json preserves the previously reported aggregates. The original per-example outputs and model/cache files were deleted after the earlier analysis. Running these commands creates new examples from the fixed revisions; it does not restore the old byte-for-byte logs. The frozen selections and measurements are described in the protocol page.
