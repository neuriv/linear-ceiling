# Cache-injection experiments

This repository contains the experiment drivers, fixed source revisions, protocols, and recorded aggregate results for the cache-injection work.

Start with [the overview](docs/index.html). The [results](docs/results.html), [replication steps](docs/replicate.html), [frozen protocols](docs/protocols.html), and [repository refutations](docs/refutations.html) are short, local HTML documents.

The original per-example outputs, prompt caches, and downloaded model files were deleted after the earlier analysis. The repository preserves the reported aggregates and can recreate per-example outputs from the pinned public sources. New run files are not byte-for-byte copies of the deleted originals. See the replication page before downloading data and models.
